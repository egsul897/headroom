# Adversarial exception suite

Fifteen synthetic cases (`cases.json`), each isolating one way a seemingly
permissive negative-covenant exception is constrained elsewhere.

Failure modes covered:

- Hanging / trailing provisos
- Article-level chapeaux
- Defined-term remote gates
- Cross-section conditions
- Notwithstanding clauses that import external instruments
- Shared builder / residual-last-resort / classify-reclassify capacity
- Qualitative unlimited carve-outs that remain gated
- Junior-prepay amendment stacks

All drafting is invented. Nothing here is tuned into the production legal engine.
