# Human interventions ledger

All interventions below are **excluded** from autonomous-success metrics.

| Kind | Detail | Affects autonomous score? |
|---|---|---|
| `DISCOVERY_MODE` | Pass B semantic discovery ran synthetic/unpaid; definition/section exception catalogs + Pass A supply deterministic candidates | No — recorded by compiler on every unpaid run |
| Package selection | Human selected MHK SEC filing as second authentic package and froze HTML/text before scoring | Freeze protocol only; not a compile-time annotation |
| Legal reference authoring | Independent MHK reference written **after** freeze for scoring (`04-independent-legal-reference.md`) | Scoring only; not fed to compiler |
| Manifest authorship | `mtn-regression.json` / `mhk-holdout.json` document paths | Runner input; no clause labels |
| PP001 baseline reuse | Relative paths into frozen PP001 sources for regression | Baseline integrity; no new MTN labels |

## Interventions deliberately not performed

- No hand-authored IR for MTN or MHK baskets
- No issuer-specific production branches
- No paid inference authorization
- No truth-set edits after scoring
- No manual overrides of `executableAuthority`
